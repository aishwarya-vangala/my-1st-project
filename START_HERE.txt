COLLEGE EVENT MANAGEMENT SYSTEM — QUICK START

1. Extract the ZIP and open the college-event-management-system folder in VS Code.
2. Install Node.js LTS if needed.
3. Create a Supabase project and run database/schema.sql in its SQL Editor.
4. Copy backend/.env.example to backend/.env.
5. Add your Supabase URL, private server-side key, and a strong ADMIN_API_KEY.
6. Open a terminal in this folder and run:
   npm install
   npm start
7. Open http://localhost:3000
8. Read README.md for complete setup and troubleshooting.

Do not upload backend/.env or share the Supabase service-role key.
